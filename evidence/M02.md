## 4. What the tests prove

| Failure injected | Asserted outcome |
|---|---|
| Garbage, empty, array, wrong type, missing field, truncated and multi-object output | fallback value; exactly two provider attempts |
| Valid JSON in prose | extracted and accepted on the first attempt |
| `TimeoutError`, HTTP 429, `ConnectionResetError` | fallback after two attempts; agent totals unaffected |
| Five failure modes through `MultiAgentOptimizer` | duration, critical path, topological order, every task's ES/EF/LS/LF/slack, deterministic risks, deterministic suggestions and narrative identical to a `NoopLLM` control |
| Invalid project with a failing provider | `ProjectError` with `llm.calls == 0` |
| Three consecutive failing `optimize()` runs | each agent's breaker opens at exactly 3 failures; provider calls stop (count frozen); fallbacks still correct |
| Reset window with `FakeClock` | open at +29.9 s, closed at +30 s; success zeroes `failure_count`; a failed probe reopens for another full window |
| Healthy provider after reset | LLM notes return (`deterministic=False`), narrative is the enriched value, breakers closed |
| Core vs graph, deterministic and failing | identical duration, critical path, narrative, risks and suggestions |

## 7. README / CV claim affected

The README already claimed "deterministic fallback on any failure" and
"circuit breaker + retry/backoff". Those claims are now demonstrated rather
than asserted, and are scoped: the schedule is computed before the provider is
consulted, so failures can only remove the optional LLM notes, never change
scheduling facts. A failure-behaviour table was added. No new claim about
provider coverage, distributed state or request-level timeouts is made.

## 8. Remaining limitations

- Breaker state is in memory and per agent instance; a new process or
  `MultiAgentOptimizer` starts closed. Each `run_langgraph` call builds fresh
  agents, so the graph path forgets failures between runs.
- One retry for every exception class; no rate-limit-aware backoff, no jitter.
- No library-level request timeout; `OpenAICompatibleLLM` passes `timeout=60`
  to `urllib`.
- `extract_json_object` is a first-`{` to last-`}` slice; multiple JSON
  objects are merged and rejected rather than disambiguated.
- The result object has no "fell back" flag; callers detect it by the absence
  of `deterministic=False` entries.
- The graph path recomputes the schedule in each node (three times per run).

Full list in `docs/M02.md`.
